# TPU Social Network — Учебный проект при ТПУ

### К моменту защиты имеется:
- Авторизация через TPU Oauth 2.0;
- Возможность редактировать профиль: менять описание, аватарку;
- Посты профиля: текст, фото, видео, документы. Возможность редактирования, оценивания, комментирования и добавления новых постов;
- Базовый роутинг
- Приятный глазу неброский дизайн в стиле университета, плавные анимации

По сложившимся обстоятельствам проект без бэкенда, только фронтенд.
